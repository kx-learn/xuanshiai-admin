# 平台配置 · 按菜单层级配置总结（接口接线说明）

> 范围：「平台配置」菜单组下全部 7 个子菜单页面
> 接线原则：**页面 UI 零改动**，仅把每个配置项接到后台配置域接口；改动即时自动保存（防抖 700~900ms），页面原有「确定提交」按钮保留，作为手动落库入口。

---

## 一、菜单等级结构

「平台配置」是后台侧栏的**一级导航分组**（与「系统管理」「公众号」等并列），其下挂 **7 个二级子菜单页面**；每个页面内部再按 Tab / 卡片分区（视为页面内的三级结构）管理不同配置域。

```
一级：平台配置（侧栏分组）
 ├─ ② 基本配置   /platform-config-basic   —— 6 个 Tab，6 个配置域
 ├─ ② 导航配置   /platform-navconfig      —— 5 组导航 + 图标样式
 ├─ ② 平台布局   /platform-page           —— 4 个 Tab（首页/资料页/团队页/电脑端）
 ├─ ② 权限配置   /power-config            —— 5 张权限卡片
 ├─ ② 内容配置   /platform-content        —— 3 个 Tab（文案/自定义页面/会员中心）
 ├─ ② 基础数据   /platform-base           —— 29 组基础字典（分类维护）
 └─ ② 收费配置   /platform-payconfig      —— 收费卡片（多区）
```

后台通用配置存储：`admin_config_snapshot` + 审计表 `admin_config_audit_log`（由 `app/services/admin_config.py` 的 `ensure_defaults()` 按 namespace 懒初始化）。

| 能力 | 接口 | 说明 |
| --- | --- | --- |
| 读配置域 | `GET /api/v1/admin/configs/{namespace}` | 返回 `{ namespace, version, config, ... }` |
| 写配置域 | `PATCH /api/v1/admin/configs/{namespace}` | 整域快照 + `version` 乐观锁 + `change_summary` 审计 |
| 变更审计 | `GET /api/v1/admin/configs/{namespace}/audit-logs` | 每次保存自动写审计 |
| 图片上传 | `POST /api/v1/admin/common/upload` | 已接入本套页面全部图片位 |

权限：读取需 `platform.config.read`，写入需 `platform.config.write`（超管 `*` 放行）；图片上传需 `matchmaker.manage`。

## 二、菜单等级配置总结（子菜单页面逐页展开）

### 1. 平台配置 › 基本配置（`/platform-config-basic`）→ 6 个配置域

| 页内 Tab（三级） | 配置域 | 配置内容 |
| --- | --- | --- |
| 基本配置 | `platform_basic` | 平台名称/宣传标语；PC端Logo、PC引导页图、抖音二维码、首页分享图片、微信一键登录LOGO、登录页标语等**图片位已接真实上传**；首页分享标题/摘要、推送消息摘要；默认籍贯地/默认现居地；男/女会员缺省头像（已接上传）；右侧分享效果预览跟随输入实时变化 |
| 运营模式 | `platform_operation` | 全平台线上+线下 / 全平台纯线下 / 指定会员纯线下 三选一 |
| 信息登记引导页配置 | `platform_register_guide` | 注册引导页展示字段与流程开关 |
| 基本资料登记配置 | `platform_register_fields` | 基本资料各字段登记开关/顺序 |
| 私密信息登记与展示配置 | `platform_private_fields` | 私密字段登记与展示开关 |
| 筛选功能配置 | `platform_filter_config` | 用户筛选功能可用项 |

### 2. 平台配置 › 导航配置（`/platform-navconfig`）→ `platform_navigation`

- **5 组导航**：头部主导航 / 头部主导航二 / 底部导航 / 首页专用导航 / 会员中心导航
  - 每组下配置：入口名称、页面路径、显示/隐藏、排序（上移/下移）
  - 每行「确定」= 立即落库（另有自动保存兜底）
- **图标样式区**：当前图标、图标名称、最佳尺寸、图标位置、更换颜色/恢复默认、一键切换风格
- 说明：一键换肤/换色为纯前端视觉演示控件，本次保留原样，不落库。

### 3. 平台配置 › 平台布局（`/platform-page`）→ `platform_layout`（4 个 Tab）

| 页内 Tab | 配置内容 |
| --- | --- |
| 手机端首页布局设置 | 首页模块开关与排序（轮播图/图标导航/数据统计/红娘喜讯/文字导航）；数据统计/文字导航/红娘喜讯/默认会员展示样式选择；文字导航栏配置（显示名称、自定义名称、活动分类选择、开关）；首页置顶/VIP 显示数量；置顶/VIP/新人推荐排序规则；数据统计栏基数；允许用户自由切换样式开关 |
| 会员资料页（委托红娘模板） | 推广红娘信息、资料页布局与展示开关 |
| 红娘团队展示页 | 导航文案、页面标题、分享描述、团队展示参数 |
| 电脑端 | PC 引导页模板选择 |

### 4. 平台配置 › 权限配置（`/power-config`）→ `platform_permissions`（5 张卡片）

| 卡片 | 内容 |
| --- | --- |
| 平台浏览展示权限 | 默认展示性别、未完善资料浏览页数、进入他人资料页权限、已脱单会员展示 |
| 会员资料页内容查看权限 | 非VIP/照片/视频浏览数量、语音/红娘说/择偶要求/资料/介绍/更多资料查看权限 |
| 会员状态更改权限 | 委托红娘/完全私密/暂停服务/我已脱单 最低 VIP 门槛 |
| 会员线上牵线权限 | 实名与承诺书要求、每日次数限制（0=不限制）、被牵线要求 |
| 其他权限 | 实名强制身份证、专属红娘展示、一证多号、头像/照片强制、婚况/学历自助修改开关 |

> 发现/社区等既有模块读取的权限限额键在整域保存时原样保留，不影响线上。

### 5. 平台配置 › 内容配置（`/platform-content`）→ 3 个配置域

| 页内 Tab | 配置域 | 配置内容 |
| --- | --- | --- |
| 文案配置 | `platform_content` | 平台首页弹窗开关（同一IP每小时一次）、注册/相亲协议、加入服务红娘/推广红娘/推广红娘中心介绍富文本、宣传口号、线下约见介绍、线下VIP提示等 |
| 自定义页面 | `platform_custom_pages` | 关于我们（富文本+配图）、私人定制名称/描述、相亲防骗提醒标题与正文（富文本）、维权/防骗行为清单等 |

- **29 组可维护字典**（每组建增删改、即改即存）：审核不通过原因模板、会员标签、客户来源/客源状态/客户意向、民族、结婚意向、职业、学历、婚姻状况、情感状态、收入状况、购房情况、宗教信仰、性格标签、爱好标签、喝酒/吸烟（含择偶要求-喝酒/吸烟）、择偶要求类目、自白模板、跟进模板、举报分类、商家分类、单位分类、线下VIP套餐、MBTI 等。
- 支持分类下「新增 / 编辑 / 删除」，操作即落库并写审计。

## 五、保存行为说明

1. 进入页面先 `GET` 配置域：服务端有值回填表单，无值使用页面内置默认值。
2. 任意输入/开关/排序/增删改后 700~900ms 防抖自动保存；成功不打扰，失败右下角轻提示。
3. 页面「确定提交/确定」按钮 = 立即落库并提示。
4. 整域快照 + `version` 乐观锁保存，后台自动写 `change_summary` 与前后值审计；409 冲突提示重试，不静默覆盖。
