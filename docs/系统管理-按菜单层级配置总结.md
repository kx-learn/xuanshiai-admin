# 系统管理 · 按菜单层级配置总结（接口接线说明）

> 范围：「系统管理」菜单下**纯配置类子页面**（系统配置、广告管理、外呼平台、短信签名、短信通知配置）。业务记录页（外呼状态/呼叫记录/短信群发/发送记录）、后台账号（账号管理/添加账号/权限分组）与系统日志沿用既有或另册处理。
> 接线原则：**页面 UI 零改动**；改动即自动保存（防抖 700~900ms），原「确定提交/保存」按钮保留为手动落库入口；图片位复用 `/admin/common/upload` 真实上传。

## 一、菜单等级结构

```
一级：系统管理（侧栏分组）
 ├─ ② 系统配置   /system-setting-basic        —— 7 个 Tab，7 个配置域
 ├─ ② 广告管理   /system-setting-adconfig     —— 13 个广告位开关 → sys_ads
 ├─ ② 电话外呼   ├─ 外呼平台 /outbound-call-platform —— sys_outbound（本次接）
 │               ├─ 外呼状态 /out-call-list        （业务记录页，未接）
 │               └─ 呼叫记录 /out-call-record      （业务记录页，未接）
 ├─ ② 短信系统   ├─ 签名配置 /sms-signature        —— sys_sms.signature（展示）
 │               ├─ 通知配置 /sms-notices          —— sys_sms.notices（开关）
 │               ├─ 短信群发 /sms-group            （业务页，未接）
 │               └─ 发送记录 /sms-record           （业务页，未接）
 ├─ ② 后台账号   ├─ 添加账号 /system-setting-admin-user-add（未接）
 │               ├─ 账号管理 /system-setting-admin-user  （未接）
 │               └─ 权限分组 /system-setting-admin-group  （未接）
 └─ ② 系统日志   /system-setting-admin-log       （业务记录页，未接）
```

读写走既有通用接口：`GET/PATCH /api/v1/admin/configs/{namespace}`（version 乐观锁 + 审计日志），无需新增路由。

## 二、按菜单等级配置总结（逐页展开）

### 1. 系统管理 › 系统配置（`/system-setting-basic`）→ 7 个配置域

| 页内 Tab（三级） | 配置域 | 配置内容 |
| --- | --- | --- |
| 基本信息 | `sys_site` | 经营主体、域名绑定、域名备案、公安备案、运营区域、客服电话、客服微信、客服微信二维码（图片已接真实上传）、电脑尾部版权（富文本）、后台LOGO（上传）、红娘工作台LOGO（上传）、用户协议（富文本）、隐私政策（富文本） |
| 注册访问 | `sys_access` | 是否开启浏览、登录安全增强、是否开启注册、IP限制类型（黑/白名单）、IP设置、注册短信验证码开关 |
| 文件存储 | `sys_storage` | 七牛 accessKey、secretKey、空间名称、上传地址、远程地址、私有队列 |
| 支付配置 | `sys_payment` | 是否启用、微信支付appid、商户号、证书类型（平台/公钥模式）、公钥证书ID、公钥、APIv2/v3密钥、p12证书、显示排序；支付宝页签保持占位 |
| 图片水印 | `sys_watermark` | 水印开关、类型（指定位置/平铺）、水印文字、缩放比例、字体大小、旋转角度、透明度、填充宽高 |
| 海报配置 | `sys_posters` | 10 类海报（平台首页/会员/视频/活动/红娘/推广/合伙/社群/单页/签到）的永久二维码属性与"扫码强制关注公众号"开关 |
| 自定义区域 | `sys_region` | 区域数据管理（省份列表，暂无数据时为空态展示；添加省份按钮为占位提示） |

### 2. 系统管理 › 广告管理（`/system-setting-adconfig`）→ `sys_ads`

- 13 个内置广告位：H5/小程序 的首页轮播图、活动页首页轮播、首页宣传广告图、会员专区广告图、诚信认证 banner、开屏广告、短视频首页轮播等。
- 每行含：广告编号、广告标题、广告类型（轮播图/图片）、平台（H5端/小程序端）、**状态开关（改动即自动保存）**。
- 「添加广告 / 编辑」按钮沿用页面现有控件，暂无弹层表单，未强行新增 UI。

### 3. 系统管理 › 电话外呼 › 外呼平台（`/outbound-call-platform`）→ `sys_outbound`

- 外呼平台服务商三选一（建讯通讯 / 厚朴通讯 / 云客）+ 当前服务商外呼账户名称 + 外呼呼叫中心地址（输入即自动保存）。
- 录音下载地址为只读回显。
- 说明：外呼为第三方服务，后端仅做本地配置存储（占位）；开户/话费/线路开通需联系服务商，接入真实外呼能力时以该配置域为准替换 provider。

### 4. 系统管理 › 短信系统 › 签名配置（`/sms-signature`）→ `sys_sms.signature`

- 展示短信签名（默认"南京信达宜管家"），从配置域读取回显。
- 签名修改需联系系统服务商申请，页面保持只读展示。

### 5. 系统管理 › 短信系统 › 通知配置（`/sms-notices`）→ `sys_sms.notices`

- 60+ 个短信通知场景（验证码、余额变动、提现/退款、审核结果、牵线、VIP 到期、活动、客源、红娘分成、合同签署等），每条含：编号、场景描述、短信内容示例、通知对象（会员/管理员）与**启用开关（改动即自动保存）**。
- 说明：开关状态本地配置存储；真实发送走腾讯云短信（需先完成签名与模板报备），`send_enabled` 统一开关一并入 `sys_sms`。

## 五、保存行为说明

1. 进入页面先 `GET` 对应配置域：服务端有值回填，无值使用页面内置默认/空值。
2. 任意输入/开关/上传后 700~900ms 防抖自动保存；成功不打扰，失败右下角轻提示。
3. 原「确定提交/保存」按钮点击立即落库并提示。
4. 整域快照 + `version` 乐观锁，后台自动记录 `change_summary` 与前后值审计。
