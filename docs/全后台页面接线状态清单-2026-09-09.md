下一步计划：以 https://www.xuanshiai.com 为功能基准逐页对标（需登录后逐页抓取功能清单；目标示例页 /admin/matchmaker-good-news-configuration 为"红娘喜报配置"，该页面在本系统中不存在，对标后将新增）。

## 分类图例

| 图例 | 含义 |
|---|---|
| ✅ 真实接口 | 页面数据读/写走后端真实 API（adminApi 或 ListPage endpoint） |
| 🟦 配置域 | 已接 `admin_config` 配置快照接口（读+存），部分配置项后端已消费（详见此前审计报告） |
| 🟨 纯UI·假数据 | 界面完整，但数据写死在前端，刷新不变、保存不落库 |
| ⬜ 纯UI·空壳 | 界面在但永远空列表/表单状态只存内存 useState，不落库 |
| ⚪ 占位跳转 | 无实际内容，仅跳转到别的页面 |
