# 原站 vs 本地 — 全站功能比对与后端缺口清单

> 比对基准：原站 `https://www.xuanshiai.com/admin/*`（已登录抓取 **115 个页面**）
> 本地：`src/app/(admin)/*` 共 **113 个页面目录**
> 后端基线：`xuanshiai/app/api/routes/*.py` 静态解析出 **779 条路由（其中 /admin 382 条）**
> 生成时间：2026-10-13

## 一、总览

| 项目 | 结果 |
|---|---|
| 原站页面 | 115 |
| 本地缺失整页 | **0**（每个原站页面都有对应本地页面） |
| 页面内控件/功能差异 | **290 项**（已剔除跨页重复的全局顶栏文案） |
| 后端已有接口、前端未接线 | 约 180 项 |
| **后端完全没有、需新增** | **7 大类**（见第四节） |
| 原站图片资源 | 140 个 URL，已下载 **139** 个到 `public/refimg/` |

**结论**：不是"页面没做"，而是**页面内的字段/弹窗/操作缺了一部分**；其中大头集中在几个功能页（线下VIP、互选活动、相亲卡、短视频）。
