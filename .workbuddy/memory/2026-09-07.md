### 共享组件修复

### 独立页面修复

- `src/components/PageSizeSelect.tsx`：新增 `down` prop，下拉菜单支持朝下展开（`.page-size-menu-down`），用于分页器底部场景；保留朝上（默认）供其它场景。去掉硬编码样式冲突。
- `globals.css`：新增 `.pg-arrow`（CSS 三角箭头）、`.page-size-select > .page-size { width:118px }`、`.page-size-menu-down`（top: calc(100%+4px)，覆盖默认的 bottom）。

### 页面接入（替换原先"只显示当前页/上一页下一页"的简陋分页）

### 账号管理页 `/reg-user-all` 分页器修复（用户反馈"明明一页数据却显示38页、每页条数选不了"）
- 根因：该页用的是**内联手写分页器**（非 AdminPagination），页码 `1 2 3 4 5 … 38` 是写死的；demo 模式把 `total` 硬编码为 38；`20 条/页⌄` 是纯文本 span 且用 Unicode 箭头。
- 处理：删除手写分页器与孤立 `<PageSizeSelect>`，改用 `<AdminPagination>`；新增 `pageSize` state；`load` 支持 `page_size`；demo 模式 `total` 改为 `items.length`、`has_more` 用 `page*pageSize<total` 计算。
- 删除了原来的 `useEffect` 手绑 `.admin-pagination` span 点击事件的遗留代码。
- 注意：凡用到该页的账号管理，接入 AdminPagination 后不再需要手动绑定页码点击事件。

### DateRangePicker 文字重叠 + 图标重复修复（用户反馈"日期选择器文字重叠"）
- 根因：`type="date"` input 无值时自带默认占位文字（"年/月/日"），与组件绝对定位的 `.dr-placeholder`（"开始日期/结束日期"）叠在一起；且每个 date input 自带一个日历小图标，组件末尾又加了一个 `<CalendarDays>`，导致结束日期旁出现两个图标。
- 处理：
  - `DateRangePicker.tsx`：无值的 input 加 `empty` class；末尾图标改为可点击的 `.dr-picker-btn`（`onClick` 调用 `input.showPicker()`，不支持时聚焦），支持原生弹窗；用 ref 指向两个 field。
  - `globals.css`：`input[type="date"]::-webkit-calendar-picker-indicator { display:none }` 隐藏自带指示器；`input.empty { color:transparent }` 隐藏默认占位文字；新增 `.dr-picker-btn` 样式。
- 备注：依赖 `HTMLInputElement.showPicker()`（Chrome 99+），后台主用 Chrome 满足。
- 二次修复（用户反馈"仍重叠且日期选不了"）：
  - `input.empty { color: transparent }` 对 `type="date"` 占位无效，改用 `::-webkit-datetime-edit` / `::-webkit-datetime-edit-fields-wrapper` 伪元素设置 `color: transparent`。
  - `showPicker()` 不可靠：为两个 input 绑 `onClick` 唤起原生选择器，`openPicker` 加 try/catch（showPicker 失败时降级 `focus()`+`click()`）；右侧 `.dr-picker-btn` 点击打开"尚未填写的那一个"。

### 分页器交互升级（用户反馈：页码变蓝/翻页位置不动/省略号跳5页/页码不多出/每页条数可选）
- `AdminPagination.tsx`：新增 `go(target)` 统一翻页——`clamp` 到 [1,totalPages]、`next===page` 时跳过、翻页前记录 `window.scrollY` 并在 `requestAnimationFrame` 中 `scrollTo` 恢复（翻页页面不滚动）。省略号改为可点击 button：tail 省略号 hover 变 `»`（`.jump-arrow i.right` 双 chevron）点击 +5，head 省略号 hover 变 `«`（`i.left`）点击 -5；`.dots`/`.jump-arrow` 在 hover 时切换。保留 `showEdges`（总页数>1 才显示上/下页按钮），`active` 高亮当前页。
- `PageSizeSelect.tsx`：彻底重写——下拉菜单由 `position:absolute` 改为 **`position:fixed` 视口定位**（用 `getBoundingClientRect` 计算 `top/left`），核心是**解决下拉被外层 `overflow-hidden` 容器裁剪导致"选不了"**；`down` 控制向上/向下弹出；加 mousedown 外部点击关闭；去掉旧 legacy 动态创建菜单逻辑。
