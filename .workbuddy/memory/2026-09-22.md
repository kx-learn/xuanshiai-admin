## 原站（www.xuanshiai.com/admin）静态逆向 — 全站筛选项基准

- **关键发现**：原站后台是 Vue3 SPA，静态资源**无需登录即可下载**。入口 `https://www.xuanshiai.com/admin/` → `assets/index.<hash>.js`（4.5MB，含完整路由表 `asyncRouterMap`），另有 143 个按页面命名的分包 chunk（`assets/list.55f5f3b0.js` 等）。
- 全部中文是 `\uXXXX` 转义，必须解码后再分析。路由表可正则提取 `path:` / `title:` / `import("./chunk")`，共 183 条路由，**path 与我们项目目录名完全一致**（可直接映射比对）。
- 筛选项提取正则（编译后的渲染函数）：
  - 下拉选项：`\{value:([^}]{0,40})\},\s*\{default:\w*\(\(\)\s*=>\s*\[.{0,140}?\b\w+\("([^"]{1,30})"`
  - 下拉标题 = 该组前一个 `placeholder:"X"`（ant-design-vue 用 placeholder 显示默认文案，如「全部账号」「注册时间(默认)」）
  - Tab：`tab:"X"`；输入框：`placeholder:"X"`
- 工具链已建好，放在 `.workbuddy/refsite/`：`extract_routes.py`（路由表）、`download_chunks.py`、`analyze.py`（单 chunk 筛选项）、`build_report.py`（全站清单）、`compare.py`（与我们页面 diff）。

## 添加客源悬浮下拉「白字看不见」— CSS 特异性冲突

- 现象：鼠标悬浮「添加客源」弹出菜单，但三个选项（单条录入/10条快录/批量导入）看不见，一片白。
- 根因：`globals.css` 中 `.customer-lead-page .lead-tabs > div:last-child button { ... color:#fff !important; width:126px; height:38px }`（约 381 行）特异性 (0,3,1) + `!important`，而下沉的 `.lead-add-menu-item` 只有 (0,1,0)。下拉菜单 DOM 就在 `.lead-tabs > div:last-child` 内，于是菜单项被强制成**白色文字**（白底白字）+ 126×38 按钮尺寸。
- 修复：改用 `.customer-lead-page .lead-tabs .lead-add-menu button.lead-add-menu-item`（(0,4,1)，文件中位置更靠后）配 `!important` 覆盖 color/width/height/min-max-height/display/padding；边框 `#edf0f5`→`#d9dde6`、阴影加强、z-index 30→100；新增 `.lead-add-menu::after` 透明 6px 桥接块，防止鼠标从按钮移到菜单经过间隙时触发 mouseleave 导致闪烁。
- 教训：**写弹层/下拉内的按钮样式前，先全局搜 `div:last-child button`、`> button` 这类带 `!important` 的宽泛规则**，它们会静默污染弹层子元素。覆盖时特异性必须 ≥ 原规则，不能只靠类选择器。
- 验证：dev server 早已在 3000 端口运行（PID 5376，自己再 `npm run dev` 会被拒绝并改占 3001）；直接 `curl localhost:3000/love-customer-list` 取 CSS chunk 链接，用 Python 正则提取规则确认新样式已编译进产物（热更新即时生效，无需 build）。
