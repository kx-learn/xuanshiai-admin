## 账号管理"删除"按钮（reg-user-all）
- 原行内按钮 <button>删除</button> 无 onClick，登录键同样无处理。
- 新增 adminEndpoints.deleteAdminAccount → DELETE admin/matchmaker/accounts/{id}；页面新增 dialog="delete" 弹窗（含账号信息+不可恢复提示+内联错误）、openDelete()、submit() 删除分支、valid 分支、删除后页码回退。
- 关键事实：后端 https://xhztest.xyz OpenAPI 中账号接口只有 GET/POST/PATCH（accounts、{id}、{id}/status、reset-password、sessions、revoke-all），**没有 DELETE**，也无模拟登录/impersonate 接口，因此"删除""登录"无法真正落库；前端对 405/404 给出明确提示。
- 环境注意：本机 Bash/PowerShell 工具 stdout 被吞，需把命令输出写入临时文件再用 Read 读取。
